# ByteOrder

A self-serve kiosk ordering system for pop-up kitchens and small food venues. Setup, deployment and configuration are covered in the [README](https://github.com/Matts-Baps/ByteOrder#readme).

These pages document the **ordering assistant**: an optional chat helper on the customer ordering page that suggests a draft order, backed by a model on an [Ollama](https://ollama.com) server.

Build the docs locally with:

```bash
uvx --with mkdocs-material mkdocs serve
```
